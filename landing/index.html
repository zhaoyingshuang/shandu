常见问题

有问题？看这里

需要翻墙吗？
不需要。闪读支持 DeepSeek、通义千问、智谱、Kimi、零一万物等国内模型，注册即可免费使用。当然也支持 OpenAI 和 Claude。
API Key 安全吗？
绝对安全。API Key 只保存在你浏览器的本地存储中，不会上传到任何服务器。所有 API 调用都是直接从你的浏览器发出。
免费额度够用吗？
DeepSeek 注册即送 500 万 tokens，足够每天使用。通义千问、智谱等也有百万级免费额度。日常使用完全够用。
Pro 版和免费版有什么区别？
Pro 版解锁无限次摘要、全部 4 种摘要模式、6 种语言翻译、导出 Markdown 等高级功能。免费版每天限 5 次，仅支持 2 种模式。
支持哪些浏览器？
目前支持 Chrome 浏览器。Edge 用户也可以安装（基于 Chromium）。后续会考虑 Firefox 支持。
