---

闪读是一款轻量级 Chrome 浏览器插件，帮助你在信息过载的时代快速获取网页核心内容。

## 核心功能

⚡ **4种摘要模式**
- 简短：一句话总结 + 关键观点，快速判断是否值得阅读
- 详细：深度分析，包含论点论据、关键数据、结论建议
- 要点：提取 8-12 条关键事实、数据、人名（Pro）
- 时间线：按时间梳理事件脉络，适合新闻/事件类文章（Pro）

🌐 **多语言翻译**
摘要结果一键翻译为中文、英语、日语、韩语、法语、德语。

🇨🇳 **支持国内免费模型**
内置 DeepSeek、通义千问、智谱 GLM-4、Kimi、零一万物，注册即可免费使用，无需翻墙。同时支持 OpenAI 和 Claude。

⌨️ **快捷操作**
- Ctrl+Shift+S 打开插件
- Ctrl+Shift+A 快速生成摘要
- 右键菜单：选中文字一键摘要或翻译

📜 **历史记录**
自动保存最近 20 条摘要，随时回看。

📄 **导出 Markdown**
一键导出摘要为 Markdown 文件，方便笔记整理。

🔒 **隐私安全**
API Key 仅保存在浏览器本地，不经过任何第三方服务器。

## 使用方法

1. 安装插件
2. 点击图标 → 设置 → 输入 API Key（推荐 DeepSeek，免费注册）
3. 打开任意网页 → 点击图标 → 生成摘要
