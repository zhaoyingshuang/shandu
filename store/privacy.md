# 闪读 隐私政策

最后更新：2026年4月

## 数据收集

闪读 **不收集任何用户数据**。具体来说：

- 我们不收集个人信息
- 我们不收集浏览历史
- 我们不收集网页内容
- 我们不使用 Cookie 或任何跟踪技术

## 数据存储

所有数据仅保存在用户浏览器的本地存储（chrome.storage.local）中：

- API Key：仅用于调用 AI 模型 API
- 历史记录：最近 20 条摘要结果
- 设置偏好：语言、模型选择等
- Pro 激活码

这些数据永远不会离开用户的浏览器。

## API 调用

当你使用摘要或翻译功能时：

1. 网页内容从当前页面提取
2. 内容直接从你的浏览器发送到你选择的 AI 模型提供商（如 DeepSeek、OpenAI 等）
3. 我们的服务器不参与此过程

各 AI 提供商有自己的隐私政策，请参阅：
- DeepSeek: https://platform.deepseek.com/privacy
- 通义千问: https://www.aliyun.com/privacy
- OpenAI: https://openai.com/privacy
- Anthropic: https://www.anthropic.com/privacy

## 第三方服务

闪读不集成任何第三方分析、广告或跟踪服务。

## 儿童隐私

闪读不面向 13 岁以下儿童，也不有意收集儿童信息。

## 变更

如果我们更新此隐私政策，我们会在此页面上发布新版本。
