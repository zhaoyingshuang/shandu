起因
为什么要做这个插件？

我是一个普通程序员，每天要读大量的技术文章、行业资讯和英文文档。

经常遇到这种情况：打开一篇 3000 字的文章，读了 5 分钟发现对自己没用。时间就这么浪费了。

有一天突然想：能不能让 AI 帮我先"读"一遍？

第一版很粗糙，就是调一下 API，把网页内容丢过去让它总结。但用起来真的爽——一篇长文 3 秒出摘要，值不值得细读一目了然。
踩坑
开发过程中踩的坑
💥

Manifest V3 迁移

Chrome 强制升级到 V3，background script 变成 service worker，一堆 API 不兼容

🔌

接了 7 家 AI 模型

DeepSeek、通义千问、智谱、Kimi、零一万物、OpenAI、Claude，每家接口都不一样

🤯

Content Script 注入时机

有些网页加载慢，content script 注入失败，重试逻辑调了好久才稳定

💰

从免费到收费

自掏腰包搭代理服务让用户免费用，后台迁移了 3 次，才找到稳定的方案

但最后都解决了 ;-)
