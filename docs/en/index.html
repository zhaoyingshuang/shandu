FAQ

Common questions

Do I need an API key?
No. Shandu ships with a built-in free proxy that lets you start summarizing immediately. If you want unlimited use or a specific model, you can add your own API key in settings.
Is my data private?
Yes. Your API keys are stored only in your browser's local storage. AI calls go directly from your browser to the provider you choose. Shandu does not collect or transmit any user data.
Which AI models are supported?
OpenAI (GPT-4o, GPT-3.5), Anthropic Claude, DeepSeek, Alibaba Qwen, Zhipu GLM-4, Moonshot Kimi, and 01.AI Yi. Most OpenAI-compatible APIs work too.
Why use Shandu instead of just ChatGPT?
ChatGPT requires copy/paste and switching tabs. Shandu gives you a summary with one click directly from any webpage, with structured output (key points, data, action items) instead of free-form text. For power users who keep ChatGPT open all day, the value is mainly speed and structure.
Which browsers are supported?
Chrome and any Chromium-based browser (Edge, Brave, Arc). Firefox support is on the roadmap.
